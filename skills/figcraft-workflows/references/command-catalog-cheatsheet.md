## 1. Atomic `batch` Composition (`$ref`, `$step`, `field`, `onError`)

The `batch` MCP tool (engine `command.batch`) executes an array of commands as **one undo step**.

### Reference Resolution Rules

- **Named Step Reference (`$ref`)**:
  - Give any step `"as": "<uniqueName>"`.
  - In any subsequent step's `params`, `{"$ref": "<uniqueName>"}` resolves to the `id` property of that step's result.
- **Positional Step Reference (`$step`)**:
  - `{"$step": 0}` resolves to the `id` returned by step `0` (zero-based index).
- **Nested Field Path (`field`)**:
  - Extract a specific key or slash-separated path from a step's result:
    - First duplicated ID: `{"$ref": "dupStep", "field": "ids/0"}`
    - Mapped copy of original layer `3` (when `edit.duplicate` is called with `map: true`): `{"$ref": "dupStep", "field": "map/3"}`
- **Error Handling (`onError`)**:
  - `"abort"` (default): Rolls back the entire batch if any step fails and names the failing step.
  - `"continue"`: Rolls back only the failed step, continues executing remaining steps, and returns `[{step, command, ok, result | error}, ...]`.

### Example: Multi-Layer Screen, Component & Instance Wiring in One `batch`

```json
{
  "label": "Build Header & CTA",
  "onError": "abort",
  "commands": [
    {
      "command": "frame.create",
      "as": "screen",
      "params": {
        "preset": "iPhone 16",
        "name": "Welcome",
        "props": {
          "layout": "vertical",
          "padding": 24,
          "gap": 16,
          "mainAlign": "spaceBetween",
          "fill": "#0F172A"
        }
      }
    },
    {
      "command": "node.create",
      "as": "btnComp",
      "params": {
        "type": "component",
        "name": "Button/Primary",
        "x": 500,
        "y": 0,
        "props": {
          "layout": "horizontal",
          "sizingH": "hug",
          "sizingV": "hug",
          "padding": [14, 24, 14, 24],
          "fill": "#3B82F6",
          "cornerRadius": 12
        }
      }
    },
    {
      "command": "node.create",
      "as": "btnLabel",
      "params": {
        "type": "text",
        "parent": { "$ref": "btnComp" },
        "text": "Get Started",
        "props": {
          "fontSize": 16,
          "fontStyle": "Bold",
          "fill": "#FFFFFF"
        }
      }
    },
    {
      "command": "component.addProperty",
      "params": {
        "id": { "$ref": "btnComp" },
        "name": "Label",
        "type": "text",
        "layer": { "$ref": "btnLabel" }
      }
    },
    {
      "command": "instance.create",
      "as": "ctaInst",
      "params": {
        "component": { "$ref": "btnComp" },
        "parent": { "$ref": "screen" }
      }
    },
    {
      "command": "node.set",
      "params": {
        "ids": [{ "$ref": "ctaInst" }],
        "sizingH": "fill"
      }
    }
  ]
}
```
